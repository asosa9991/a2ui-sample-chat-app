DEBUGGING TIPS
═══════════════════════════════════════════════════════════════════════════════

Agent Not Starting:
  $ python agent.py
  Error: ModuleNotFoundError: No module named 'fastapi'
  → Fix: pip install fastapi uvicorn anthropic

JSON Not Valid:
  $ python test_prompts.py
  ❌ Query: "..."
  JSON error: ...
  → Fix: Improve system prompt (add examples, be more specific)

Android Can't Connect:
  Logcat: "java.net.ConnectException: Connection refused"
  → Check: Is agent running? Is URL correct (10.0.2.2)?
  → Check: Firewall blocking port 8000?

UI Not Rendering:
  Logcat: "Missing component: ..."
  → Check: Component ID exists in surfaceUpdate
  → Check: Root component is defined
  → Check: No circular references

SSE Not Streaming:
  Logcat: "No JSON found"
  → Check: Agent returning valid JSONL?
  → Check: curl output locally: curl -X POST "..."
  → Check: Data being sent: data: {JSON}\n\n format

COMMON PITFALLS & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

Pitfall 1: LLM outputs markdown JSON
  Problem: ```json\n[...]\n```
  Solution: Add to prompt: "Return ONLY raw JSON array, no markdown"

Pitfall 2: Component references non-existent child
  Problem: "child": "item_1" (but item_1 not defined)
  Solution: Ensure all referenced components are in surfaceUpdate

Pitfall 3: Mixing literal and path bindings
  Problem: {"text": {"literalString": "...", "path": "/..."}} (both keys)
  Solution: Use ONLY one: either literalString OR path

Pitfall 4: Android emulator can't reach agent
  Problem: Logcat shows "Connection refused"
  Solution: Use 10.0.2.2 (special IP for emulator) not 127.0.0.1

Pitfall 5: Circular component references
  Problem: Column → child: Row → children: [Column]
  Solution: Verify component tree is acyclic

Pitfall 6: Missing surfaceId consistency
  Problem: beginRendering says "surface_1" but surfaceUpdate says "surface_2"
  Solution: Use same surfaceId in all operations for same surface
